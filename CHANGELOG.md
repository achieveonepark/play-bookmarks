# Changelog

## 0.1.0

- Independent UPM package with managed reference bookmark steps.
- UI Toolkit library, profile editor, and execution status.
- Native Unity editor styling and .pbm importer with editable Apply/Revert inspector.
- Scene GUID resolution, custom step JSON, and lossless preservation of unavailable steps.
- Ready signals, target lookup, unscaled timeouts, cancellation, and nested iterator cleanup.
- Game action interface and runnable scene generator sample.
- Edit mode and Play mode behavior tests.
